# Pre-Campaign Store Fix List (evidence-based)

Each fix links to an observation in `03-launch-baseline.md`. Finish the **P1** items before any money goes into ads. Paying to send traffic to a page that does not convert wastes the test budget.

| # | Priority | Fix | Evidence | Owner | Done |
|---|---|---|---|---|---|
| 1 | P1 | Install **GA4** + Meta Pixel via Shopify apps (Google & YouTube, Facebook & Instagram); verify `view_item`, `add_to_cart`, `begin_checkout`, `purchase` in GA4 DebugView | No tracking; funnel only visible in Shopify | | ☐ |
| 2 | P1 | Add a **delivery & payment bar** on every product page: areas served, fee, delivery time, cash on delivery yes/no | Shoppers can't see the terms until checkout | | ☐ |
| 3 | P1 | **Real photos** (phone + white sheet + daylight) for the ~12 campaign hero products; keep renders as secondary images | Main images are generated renders, which hurts trust | | ☐ |
| 4 | P1 | Floating **WhatsApp "Ask before ordering"** button with a pre-filled message that includes the product name; use a tracked `wa.me` link | Customers in this category want advice before they buy | | ☐ |
| 5 | P1 | One **real end-to-end test order** on mobile (then refund it) | 1 checkout attempt, 0 completed, cause unknown | | ☐ |
| 6 | P2 | Rename duplicate titles to add a distinguishing detail (e.g. "Brax Chrome Mixer: Wall, 1/2", Double Handle") | 3 × "70×50cm LED Mirror", 3 × "Brax Chrome Mixer" | | ☐ |
